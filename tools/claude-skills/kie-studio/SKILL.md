# kie-studio: генерация через kie.ai с согласованием цены

kie.ai — один ключ к 200+ моделям (видео, картинки, озвучка, музыка), оплата
кредитами с баланса. 1 кредит ≈ $0.005 (так считает сам каталог kie.ai).

Скрипт: `scripts/kie.py` (Python 3.9+, без зависимостей). Ключ берётся только из
переменной `KIE_API_KEY`: никогда не проси его в чате и не пиши в файлы. В облачной
сессии Claude Code, где ключ сохранён как сетевой секрет для `api.kie.ai`, запускай с
`KIE_API_KEY=proxy-injected` — прокси подставит настоящий.

## Главное правило: ни одной платной генерации без «да»

Перед каждым запуском (и перед каждой серией) покажи человеку варианты и дождись
явного выбора. Без этого `kie.py run` не запускай. Что согласуется:

1. **Модель** — под задачу (таблица ниже), с объяснением в одну строку, почему она.
2. **Качество** — разрешение (480p / 720p / 1080p / 4K, для картинок 1K / 2K / 4K),
   со звуком или без, режим (std / pro / fast / quality).
3. **Длительность** — секунды на ролик, количество роликов, итог в минутах для серии.
4. **Цена** — в кредитах и долларах за штуку и за всё, плюс баланс до и после.
5. **Надёжность** — успешность модели за сутки (`kie.py rate`), если ниже ~90 % — скажи.

Формат предложения — 2–3 варианта, рекомендованный первым:

```
Задача: оживить кадр с героем, 9:16, 5 сек, без звука.
Баланс: 3077 кредитов (≈ $15.39).

| Вариант | Модель | Качество | Длит. | Цена | Успешность 24ч |
|---|---|---|---|---|---|
| ✅ Оптимум | kling-3.0/video | 720p std, без звука | 5 с | 75.5 кр (≈ $0.38) | 97.7 % |
| Эконом (черновик) | bytedance/seedance-2-mini | 720p | 5 с | ~41 кр (≈ $0.21) | … |
| Максимум | kling-3.0/video | 1080p pro, со звуком | 5 с | 151 кр (≈ $0.76) | 97.7 % |

После «Оптимума» останется ≈ 3002 кредита. Какой вариант запускаем?
```

Правила согласования:
- **Цены — только из живого каталога** (`kie.py price MODEL` или `kie.py models`), не из
  памяти и не из этого файла: прайс kie.ai меняется. Если цена задана «за секунду», умножь
  на длительность; если «за ролик» — учти, какие длительности бывают (смотри `schema`).
- **Любое изменение после «да»** (модель, разрешение, длительность, звук, число роликов)
  — новое согласование. Повтор после неудачи — тоже: сначала скажи, списались ли кредиты
  (`creditsConsumed` в результате, баланс до/после), и спроси, повторять ли.
- **Серия** (мультфильм, несколько сцен): согласуй потолок бюджета на всю серию и цену
  одной сцены. Подходишь к потолку — остановись и спроси.
- **Сначала дешёвый пробник.** Для новой сцены или нового стиля предложи 1 кадр картинкой
  (1–10 кр) или короткий черновик в 480–720p, и только после одобрения — финал.
- **Не хватает баланса** — не запускай; скажи, сколько нужно, и предложи дешевле.
- Человек сказал «согласовывать не надо, лимит N кредитов» — работай в пределах N
  без вопросов, но отчитывайся о каждой трате и остановись на лимите.

## Kling и другие китайские модели — через kie.ai

Решение студии (2026-11-06): подписку Kling не оформляем, оплатить её из России
неудобно. Kling (`kling-*`), Seedance, Hailuo, Vidu, Wan и остальные идут через
kie.ai, оплата кредитами kie.ai. Одного героя во всех сценах держим референсными
кадрами (`image_urls`, `kling_elements` и аналогичные поля по схеме модели).
Плагин Kling AI (`kling-ai:*`) не используем, пока человек явно не скажет, что у
него оплачен тариф на kling.ai.

## Подбор модели под задачу

Ниже — ориентир, какие семейства смотреть (снимок каталога 2026-11-06). Перед
предложением всегда проверь живой список: `kie.py models --type "<тип>"` и цену.

| Задача | Тип в каталоге | Куда смотреть |
|---|---|---|
| Кадр, персонаж, раскадровка, обложка | Text to Image / Image to Image | черновик: `z-image`, `flux-3/klein-*`, `seedream/5-flash-*`; качество: `nano-banana-2-1`, `gpt-image-2-*`, `seedream/5-pro-*`, `google/imagen4-ultra`; один персонаж в разных позах — модели с референсами (`nano-banana-*`, `flux-2/*`, `ideogram/character`) |
| Оживить картинку (главный путь для мультфильма) | Image to Video | `kling-3.0/video`, `kling/v3-turbo-image-to-video`, `bytedance/seedance-2*`, `hailuo/2-3-*`, `wan/2-7-image-to-video`, `vidu-q4/image-to-video` |
| Один герой во всех сценах | Image to Video (reference) | `kling-4.0/reference-to-video`, `vidu-q4/reference-to-video`, `wan/2-7-r2v`, `happyhorse*/reference-to-video` |
| Сцена из текста без картинки | Text to Video | `veo-3-1`, `kling-3.0/video`, `bytedance/seedance-2*`, `wan/3-0-video` |
| Дешёвый черновик движения | Text/Image to Video | `bytedance/seedance-2-mini`, `bytedance/v1-lite-*`, `grok-imagine/*` 480p, `pixverse-v6/*` 360–540p |
| Говорящий персонаж, липсинк | Lip Sync / Speech to Video | `kling/ai-avatar-*`, `omnihuman-2-0`, `infinitalk/from-audio`, `wan/2-2-a14b-speech-to-video-turbo`, `volcengine/video-to-video-lip-sync` |
| Озвучка на русском | Text to Speech | `elevenlabs/text-to-speech-multilingual-v2` (качество), `elevenlabs/text-to-speech-turbo-2-5` (дешевле), `elevenlabs/text-to-dialogue-v3` (диалог) |
| Музыка, джингл | Text to Music | `ai-music-api/generate` (Suno) |
| Апскейл, чистка | Image Editing и др. | `recraft/crisp-upscale`, `topaz/*` |

Как выбирать между ними:
- **Стиль мультфильма** (аниме, 3D, пластилин, акварель, комикс) задаётся промптом и
  стартовым кадром, а не моделью. Надёжнее всего: сначала нарисовать ключевой кадр в
  стиле картинкой (дёшево, можно перебрать), потом оживлять его image-to-video.
- **Вертикаль 9:16** — проверь в схеме, что модель её умеет (`aspect_ratio`).
- **Звук**: если ролик потом идёт в монтаж с озвучкой и музыкой — генерируй без звука,
  это дешевле (у Kling почти вдвое).
- **Длина**: большинство моделей дают 5–10 с за раз (Kling 3.0 — до 15 с). Минута
  мультфильма = 6–12 сцен; считай цену серии сразу.
- Чужих узнаваемых персонажей, логотипов и реальных людей без согласия не генерируй;
  «в стиле аниме / 3D-мультфильма» — можно, «как в мультфильме студии X с её героем» — нет.

## Порядок работы

1. Пойми задачу: что на выходе (кадр, ролик, серия, голос, музыка), формат (9:16 / 16:9),
   длительность, стиль, есть ли исходники (фото, кадр, голос).
2. `kie.py balance`; `kie.py models --type "…"` → 2–3 кандидата; для каждого `kie.py price`
   и `kie.py rate` (запросы каталога ограничены 1 в секунду — скрипт сам выдерживает паузу).
3. `kie.py schema MODEL` — какие поля обязательны, какие значения допустимы (разрешение,
   длительность, звук). Предлагай только то, что модель реально принимает.
4. Покажи таблицу вариантов (формат выше) → дождись выбора.
5. Входные файлы с диска: `kie.py upload FILE` → временная ссылка (живёт 24 ч), её в `input`.
6. Запуск:
   ```bash
   python scripts/kie.py run MODEL --input '{"prompt": "...", ...}' \
     --est 75.5 --approved "Оптимум: kling 3.0, 720p, 5 с, без звука" \
     --out <папка проекта>/kie --name scene-01 --log <папка проекта>/kie-log.jsonl
   ```
   Скрипт проверит баланс, дождётся результата и **сразу скачает файлы** (kie.ai хранит
   их 14 дней). Не дождался — `kie.py status TASK` и `kie.py fetch TASK --out …`.
7. Отчёт: файл, сколько согласовали и сколько списано (`credits`), остаток баланса.
   Итог по проекту — `kie.py log --log <файл>`.

## Если что-то не работает

- `KIE_API_KEY is not set` — на компьютере: `export KIE_API_KEY=...` (ключ на
  https://kie.ai/api-key); в облаке: ключ сохраняется как сетевой секрет для `api.kie.ai`,
  а переменная — `proxy-injected`.
- `code 402` — не хватает кредитов; `422` — параметры не по схеме (перечитай `schema`);
  `429` — частые запросы, скрипт сам повторяет; `455` — модель недоступна, предложи другую.
- Загрузка файлов идёт на отдельный адрес `kieai.redpandaai.co` (тот же ключ). В облаке
  его тоже нужно разрешить и сохранить для него ключ.
- Ответ HTTP 200 ещё не успех: смотри `code` в теле — скрипт это делает сам.
