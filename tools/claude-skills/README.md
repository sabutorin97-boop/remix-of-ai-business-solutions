# Скиллы Claude для студии

Скиллы, которые студия держит в своём аккаунте Claude. К сборке сайта отношения не имеют.

## kie-studio

Генерация картинок, видео, мультфильмов, озвучки и музыки через kie.ai по ключу.
Правило внутри: модель подбирается под задачу, а качество, длительность и цена
согласуются с человеком до каждого платного запуска. Скрипт `scripts/kie.py` без
согласования (`--approved`) и при нехватке баланса генерацию не запускает, траты пишет
в `kie-log.jsonl`.

### Установка во все проекты

Скиллы аккаунта claude.ai сами подтягиваются в Claude Code — и на компьютере, и в
облачных сессиях. Поэтому ставится один раз:

1. claude.ai → Настройки → Возможности (Capabilities) → Скиллы → «Загрузить скилл».
2. Выбрать `dist/kie-studio.zip` из этой папки.

После правки скилла архив пересобирается так (из этой папки):

```bash
rm -f dist/kie-studio.zip && zip -qr dist/kie-studio.zip kie-studio -x '*/__pycache__/*'
```

и загружается заново.

### Ключ

- **На компьютере:** `export KIE_API_KEY=...` в профиле оболочки (`~/.zshrc`, `~/.bashrc`).
  Ключ — на https://kie.ai/api-key. В чат и в файлы ключ не пишется.
- **В облаке Claude Code:** ключ сохранён как сетевой секрет окружения Default для
  `api.kie.ai`; скрипт запускается с `KIE_API_KEY=proxy-injected`, прокси подставит
  настоящий. Для загрузки своих файлов в модели нужен ещё хост `kieai.redpandaai.co`.

### Официальный справочник kie.ai

Дополнительно можно поставить официальный скилл `kie-models` (документация API):

```bash
npx skills add https://kie.ai
```
