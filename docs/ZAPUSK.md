# Запуск: что сделать руками и в каком порядке

Всё, что можно было сделать кодом, сделано. Осталось то, что требует доступов
в чужие панели. Здесь шаги по порядку: каждый занимает от пяти минут до
получаса, и после каждого есть проверка, по которой видно, что шаг удался.

Порядок не случайный: первый шаг оживляет заявки с сайта, второй даёт цифры
по рекламе, остальные — про продажи.

---

## Шаг 1. Поднять релей Telegram

**Зачем.** С боевого IP Timeweb адрес `api.telegram.org` закрыт. Пока релея
нет, молчат уведомления о заявках с сайта и партнёрский бот: человек оставляет
заявку, а вы о ней не узнаёте.

**Что делать.**

1. Зайдите на dash.cloudflare.com, зарегистрируйтесь, если аккаунта нет.
2. Слева выберите Workers & Pages → Create → Workers → Create Worker.
3. Дайте имя, например `tg-relay`, нажмите Deploy. Воркер создастся с
   заглушкой.
4. Нажмите Edit code, удалите содержимое и вставьте код релея из
   `PARTNER_BOT.md`, раздел «Если Telegram недоступен с сервера».
5. Нажмите Deploy. Скопируйте адрес воркера, он выглядит как
   `https://tg-relay.ваш-аккаунт.workers.dev`.

**Проверка.** Откройте в браузере адрес воркера с любым путём, например
`https://tg-relay.ваш-аккаунт.workers.dev/bot123/getMe`. Ответ должен прийти
от Telegram (ошибка про неверный токен — это правильный ответ, значит запрос
дошёл). Страница «Not found» означает, что код вставлен не целиком.

Если Cloudflare с сервера тоже недоступен, тот же прокси поднимается на любом
VPS вне зоны РУ: `proxy_pass https://api.telegram.org;` в nginx.

## Шаг 2. Вписать переменные в панели Timeweb

**Где.** Timeweb Cloud → ваше приложение → Настройки → Переменные окружения.

Добавьте три штуки:

| Переменная | Значение | Зачем |
| --- | --- | --- |
| `TELEGRAM_API_BASE` | адрес воркера из шага 1, без слэша на конце | оживляет исходящий Telegram |
| `CLICKS_REPORT_SECRET` | длинная случайная строка | открывает сводку переходов |
| `VITE_YANDEX_METRIKA_ID` | номер счётчика из шага 4 | включает Метрику |

Секрет для отчёта сгенерируйте локально и никому не пересылайте:

```bash
openssl rand -hex 32
```

**Важно про третью переменную.** `VITE_`-переменные подставляются на этапе
сборки, а не при запуске. После добавления нужен полный передеплой
приложения, а не перезапуск контейнера. Первые две подхватываются при
перезапуске.

**Проверка.** После деплоя откройте:

```
https://aiprofigrup.ru/api/telegram/partner?secret=<TELEGRAM_PARTNER_WEBHOOK_SECRET>&action=ping
```

В ответе поле `apiHost` должно показывать адрес воркера, а не
`api.telegram.org`. Затем отправьте тестовую заявку с сайта — уведомление
должно прийти в Telegram.

## Шаг 3. Проверить учёт переходов

**Зачем.** Убедиться, что клики по кнопке подписки считаются до запуска
рекламы, а не после слива бюджета.

1. Откройте `https://aiprofigrup.ru/go/tg?s=test&p=check` — должно
   перебросить в канал.
2. Откройте сводку:
   ```
   https://aiprofigrup.ru/go/tg?report=1&secret=<CLICKS_REPORT_SECRET>
   ```
   В ответе должна появиться метка `test` со счётчиком 1.

Если сводка отвечает 503, переменная секрета не задана. Если счётчик пустой,
проверьте, что в приложении заданы переменные бакета `S3_*` — учёт пишет
события туда же, где лежат заявки.

Метки для рекламных кампаний ставьте в ссылке объявления:
`https://aiprofigrup.ru/tg` для посадочной, а если ведёте прямо в канал —
`https://aiprofigrup.ru/go/tg?s=direct` для Яндекс.Директа и
`?s=vk` для VK Ads. Они считаются платным трафиком автоматически.

## Шаг 4. Счётчик Яндекс.Метрики и цель

**Зачем.** Метрика показывает поведение на странице. Переходы в канал считает
наш собственный учёт из шага 3, Метрика их видит не полностью — она грузится
только после согласия в баннере.

1. metrika.yandex.ru → Добавить счётчик, домен `aiprofigrup.ru`.
2. Скопируйте номер счётчика, впишите в `VITE_YANDEX_METRIKA_ID` (шаг 2) и
   передеплойте приложение.
3. В счётчике → Настройка → Цели → Добавить цель → тип «JavaScript-событие»,
   идентификатор `tg_subscribe_click`.
4. Тем же способом заведите остальные цели, они уже отправляются кодом:
   `tg_click`, `tg_channel_click`, `tg_bonus_claim_click`, `quiz_complete`,
   `calc_request`, `lead_magnet_download`, `contact_submit`.

**Проверка.** Откройте сайт, примите баннер согласия, нажмите кнопку
подписки. В Метрике → Отчёты → Конверсии цель появится в течение получаса.

## Шаг 5. Именованные пригласительные ссылки канала

**Зачем.** Разделить в отчёте Telegram платных подписчиков и бесплатных.
Наш учёт метку уже различает, но сколько человек реально вступило, показывает
только Telegram, и только по именованным ссылкам.

1. В Telegram откройте канал → Управление каналом → Пригласительные ссылки.
2. Создайте две ссылки: одну назовите «Реклама», вторую «Сайт».
3. Скопируйте адреса вида `t.me/+…` и впишите в переменные на Timeweb:
   `TELEGRAM_CHANNEL_LINK_ADS` — рекламную, `TELEGRAM_CHANNEL_LINK_SITE` —
   вторую. Перезапустите приложение.

**Проверка.** Откройте `https://aiprofigrup.ru/go/tg?s=ads` и
`https://aiprofigrup.ru/go/tg?s=site` — они должны вести на разные адреса.
Дальше число вступивших по каждой видно в том же разделе управления каналом.

## Шаг 6. Проверить микроразметку в Яндексе

**Зачем.** Разметка нужна, чтобы Яндекс показывал блок вопросов в выдаче, а
нейропоиск цитировал ответы. Ошибка в ней обесценивает работу.

1. Откройте валидатор: webmaster.yandex.ru/tools/microtest/
2. Прогоните по очереди адреса демо:
   - https://sabutorin97-boop.github.io/remix-of-ai-business-solutions/faq/
   - https://sabutorin97-boop.github.io/remix-of-ai-business-solutions/
3. Ожидаемый результат: находятся типы `Organization` (или
   `ProfessionalService`) и `FAQPage`, ошибок нет.
4. Для самого сайта студии добавьте `aiprofigrup.ru` в Яндекс.Вебмастер, если
   ещё не добавлен, и посмотрите раздел «Инструменты → Валидатор
   микроразметки».

Сборщик уже проверяет, что текст в разметке дословно совпадает с видимым на
странице, — это то, на что Вебмастер ругается чаще всего. Но прогон живой
страницы всё равно нужен: он показывает, что видит поисковик.

## Шаг 7. Первые продажи

Материалы готовы, осталось опубликовать и ответить желающим.

1. Возьмите пост про AI-FAQ из `docs/posts/ai-faq.md` — там уже вставлены
   ссылки на живое демо.
2. Опубликуйте в канале и в VK, вариант для каждой площадки в файле.
3. Условие скидки для первых двух клиентов — `docs/SKIDKA_ZA_KEYS.md`.
   Короткий текст для переписки в конце документа: отправляете его клиенту,
   получаете «условия принимаю» и начинаете работу.
4. Отмечайте клиентов в таблице учёта в конце того же документа, иначе через
   месяц не вспомнить, кто что разрешил.

## Про OpenRouter

Для этого сайта ключ OpenRouter бесполезен: их Cloudflare отдаёт 403 на
запросы с IP Timeweb, это проверено вживую и воспроизводится на каждом
запросе. Поэтому AI-чат «Макс» и наставник в партнёрском боте работают через
kie.ai (`KIE_API_KEY`), см. комментарий в `src/lib/ai-gateway.ts`.

Если ключ нужен другому проекту, который крутится не на Timeweb, — это его
дело, к сайту студии отношения не имеет.
