# AI-FAQ

Продукт студии: страница вопросов и ответов, которую собирает не копирайтер, а
генератор. На входе файл с вопросами, на выходе три файла, которые ставятся на
сайт клиента как есть. Цена 7 000–10 000 ₽, срок 1–2 дня.

```bash
python generate.py schema/example.json dist/
```

Нужен Python 3.11+ и Jinja2 (`pip install jinja2`). Больше ничего.

Живое демо: <https://sabutorin97-boop.github.io/remix-of-ai-business-solutions/faq/>

## Сборка страницы за 20 минут

1. **Соберите сырые вопросы** у клиента: скриншотами переписки, списком в
   блокноте — как есть.
2. **Скопируйте** `schema/example.json` в `clients/название/faq.json`.
3. **Перепишите вопросы и ответы** по правилам ниже. Это основная работа,
   остальные поля заполняются за пару минут.
4. **Подгоните оформление** в разделе `design`: акцентный цвет под сайт
   клиента, светлая или тёмная страница, шрифтовая пара и скругления.
5. **Соберите:**
   ```bash
   python generate.py clients/название/faq.json clients/название/dist/
   ```
   Сборщик напечатает вес страницы и замечания: слишком длинный ответ,
   короткий список, ссылка внутри ответа.
6. **Отдайте клиенту** три файла из `dist/`: `index.html`, `style.css`,
   `script.js`. Кладутся в любую папку сайта, правок в его коде не требуют.

## Правила текста

Проверяются при сборке и печатаются замечаниями:

- **3–7 вопросов на страницу.** Меньше — блок не заметят, больше — размывается.
- **Ответ 40–120 слов**, самодостаточный: он должен быть понятен отдельно от
  страницы. Не «да, конечно», а полный ответ с условиями и цифрами.
- **Без ссылок внутри ответа.** В сниппете они не кликаются, а текст ломают.
- **Пишите то, что реально спрашивают** в переписке, а не то, что удобно
  отвечать.

Зачем разметка в 2026 году: Google не показывает FAQ-аккордеон в выдаче с
7 мая 2026, но Яндекс показывает, а нейропоиск легко цитирует короткие точные
ответы. Текст в разметке обязан дословно совпадать с видимым — за этим следит
сборщик, расхождение Яндекс.Вебмастер считает ошибкой.

## Что заполнять в JSON

| Раздел | Обязательно | Что туда писать |
| --- | --- | --- |
| `meta` | `title`, `description` | Заголовок вкладки (до 70 символов) и описание для выдачи (до 200). `url` — адрес страницы на сайте клиента |
| `brand` | `name` | Название, одна строка о деле, адрес сайта для ссылки «На сайт», логотип |
| `intro` | `headline` | Заголовок страницы, пояснение и дата обновления |
| `faq` | минимум один | Сами вопросы и ответы |
| `cta` | — | Блок «не нашли ответ»: заголовок, текст, кнопка и её адрес |
| `contacts` | — | Телеграм, телефон, WhatsApp, почта, часы работы |
| `design` | — | `scheme` (light/dark), `accent` (цвет сайта клиента), `font` (sans/serif), `radius` (sharp/soft/round) |
| `legal` | — | Лицо и ИНН для подвала |

Хотя бы один контакт или адрес кнопки обязателен: иначе человеку с вопросом
некуда обратиться, и сборщик об этом скажет. Полный список полей —
`schema/faq.schema.json`.

## Общий FAQ-модуль

`faq_module/` — единственная реализация аккордеона и разметки `FAQPage` на все
продукты студии. Соседние генераторы подключают модуль, а не копируют вёрстку:
правка здесь расходится по всем собранным сайтам сразу.

| Файл | Назначение |
| --- | --- |
| `faq_module/faq.py` | нормализация вопросов, JSON-LD, проверки текста |
| `faq_module/schema_check.py` | проверка входного JSON по схеме, сообщения на русском |
| `faq_module/templates/faq.html.j2` | секция с аккордеоном на `<details>` |
| `faq_module/static/faq.css` | стили, цвета берутся из переменных страницы |
| `faq_module/static/faq.js` | плавное раскрытие поверх рабочего `<details>` |

Как подключить из другого продукта:

```python
import sys
sys.path.append("../ai-faq")

from faq_module import TEMPLATE_DIR, faq_jsonld, faq_script, faq_styles, normalize_faq
from faq_module.schema_check import DataError, Naming, check, load_json
```

Шаблон ждёт переменные `faq_items`, `faq_title` и необязательные
`faq_help_text`, `faq_help_url`, `faq_help_link_text`. Стили и скрипт
возвращаются строками — продукт склеивает их со своими в один файл, чтобы у
собранной страницы не было лишних запросов.

Аккордеон построен на `<details>`: раскрывается и работает с клавиатуры даже
при отключённом JavaScript. Скрипт добавляет только плавность и молчит при
`prefers-reduced-motion: reduce`.

## Чего здесь намеренно нет

Аналитики, cookie-баннера, CDN, внешних шрифтов и иконочных библиотек. Форм
на странице тоже нет: вопрос задаётся в мессенджере или по почте, поэтому
персональные данные страница не собирает и согласие не требуется.
