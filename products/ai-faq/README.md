# AI-FAQ — общий модуль FAQ

Здесь лежит единственная реализация FAQ для продуктов студии: аккордеон,
его стили и скрипт, генератор разметки `FAQPage` и проверки текста ответов.

Продукты подключают модуль, а не копируют вёрстку. Правка здесь расходится
по всем собранным сайтам сразу, поэтому второй аккордеон писать не нужно.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `faq_module/faq.py` | нормализация вопросов, JSON-LD, предупреждения по тексту |
| `faq_module/templates/faq.html.j2` | секция с аккордеоном на `<details>` |
| `faq_module/static/faq.css` | стили, цвета берутся из переменных темы продукта |
| `faq_module/static/faq.js` | плавное раскрытие поверх рабочего `<details>` |

## Как подключить

```python
import sys
sys.path.append("../ai-faq")

from faq_module import TEMPLATE_DIR, faq_jsonld, faq_styles, faq_script, normalize_faq

items = normalize_faq(client["faq"])          # пустые записи отбрасываются
markup = faq_jsonld(items)                    # None, если вопросов нет
```

Шаблон ждёт переменные `faq_items`, `faq_title` и необязательные
`faq_help_text`, `faq_help_url`, `faq_help_link_text`. Каталог `TEMPLATE_DIR`
добавляется в загрузчик Jinja2 рядом с шаблонами продукта.

Стили и скрипт возвращаются строками — продукт склеивает их со своими в
один `style.css` и один `script.js`, чтобы у собранной страницы не было
лишних запросов.

## Правила текста

Проверяются функцией `faq_warnings()` и печатаются при сборке:

- 3–7 вопросов на страницу;
- ответ 40–120 слов, самодостаточный — он должен читаться отдельно от страницы;
- без ссылок внутри ответа: в сниппете они не кликаются.

Google с 7 мая 2026 не показывает FAQ-аккордеон в выдаче, разметка при этом
остаётся валидной. Цель разметки — Яндекс, который ограничениям Google не
следует, и цитируемость нейропоиском.

## Аккордеон без JS

Секция построена на `<details>`: раскрывается и работает с клавиатуры даже
при отключённом JavaScript. Скрипт добавляет только плавность и молчит при
`prefers-reduced-motion: reduce`.
