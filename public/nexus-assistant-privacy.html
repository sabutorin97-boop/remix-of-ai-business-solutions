Политика конфиденциальности Nexus Assistant

Дата последнего обновления: 11 октября 2026 г.

Этот документ описывает, какие данные обрабатывает приложение Nexus Assistant и как они используются. Приложение представляет собой персонального AI-ассистента, которым владелец сайта aiprofigrup.ru пользуется для управления собственным календарём, почтой и документами. Приложение не является публичным сервисом и не предоставляется третьим лицам.

Какие данные обрабатываются

Приложение получает доступ к данным аккаунта Google только после явного разрешения владельца этого аккаунта, выданного через стандартный экран согласия Google. Запрашиваются следующие разрешения:

  • Google Календарь (создание, чтение и изменение событий) — чтобы вести расписание владельца по его текстовым и голосовым запросам.
  • Gmail (чтение, изменение и отправка писем) — чтобы готовить и отправлять письма по прямому поручению владельца.
  • Google Диск, Документы, Таблицы, Презентации — чтобы создавать и редактировать рабочие файлы по поручению владельца.

Данные других пользователей приложение не запрашивает и не собирает.

Как используются данные

Исключительно для выполнения задач, которые владелец аккаунта ставит ассистенту напрямую. Данные не продаются, не передаются третьим лицам, не используются для рекламы, профилирования или обучения моделей машинного обучения.

Использование информации, полученной через Google API, соответствует Политике Google API Services User Data, включая требования раздела Limited Use.

Где хранятся данные

Токены доступа хранятся в файле с ограниченными правами доступа на частном сервере владельца и не передаются никуда, кроме серверов Google при выполнении запросов к их API. Содержимое календаря, писем и файлов не копируется в отдельное хранилище.

Для обработки естественного языка текст запроса и необходимый для ответа фрагмент данных могут передаваться поставщику языковой модели, используемой ассистентом. Такие данные передаются только в объёме, нужном для выполнения конкретной задачи.

Как отозвать доступ

Владелец аккаунта может в любой момент отозвать выданные разрешения на странице Сторонние приложения с доступом к аккаунту. После отзыва приложение немедленно теряет доступ к данным, а хранящиеся токены становятся недействительными.

Хранение и удаление

Приложение не ведёт собственной базы пользовательских данных. Для удаления токенов доступа достаточно отозвать разрешения по ссылке выше либо обратиться по контакту ниже.
